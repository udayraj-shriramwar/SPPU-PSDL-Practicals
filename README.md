# SPPU PAL Practicals

This repository contains **Parallel Programming / Embedded Systems Laboratory (PAL) practical assignments** based on the SPPU practical problem statements.

## 📚 Practicals

### 1. Embedded C Programming — Addition of Two Numbers
Study of Embedded C programming language and implementation of a program to add two numbers.

### 2. Embedded C — Array Addition
Write an Embedded C program to add an array of `n` numbers.

### 3. Embedded C — Memory Block Transfer
Write an Embedded C program to transfer elements from one memory location to another:
- Internal to Internal memory transfer
- Internal to External memory transfer

### 4. PIC18FXXX — LED Blinking
Interface PIC18FXXX with an LED and blink the LED using a specified delay.

### 5. PIC18FXXX — LCD Interfacing
Interface an LCD screen with PIC18FXXX and display the required output.

### 6. Timer Programming — ISR Based Buzzer
Implement timer programming using an **Interrupt Service Routine (ISR)** to turn a buzzer ON/OFF.

### 7. PWM Generation — Servo/DC Motor
Generate a **PWM signal** for controlling a Servo/DC motor using Embedded C.

### 8. Temperature Sensor — ADC and LCD
Interface a temperature sensor with PIC18FXXX, use **ADC** to read the temperature and display the result on an LCD.

### 9. Arduino Board and Raspberry Pi OS
Study the **Arduino board** and understand the installation process of **Raspberry Pi OS**.

### 10. Arduino — LED Blinking
Implement a simple program using an open-source prototype platform such as Arduino for:
- Digital read/write using LED and switch
- Analog read/write using sensors and actuators
- LED blinking using Arduino
